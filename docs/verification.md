# 验证

求解之后，`solver/verify.py` 用与求解步骤分开的计算检查答案。验证不通过时仍保留答案，并在 `Solution.verified` 和 `Solution.verification` 里标明。调用方可以据此决定是否重试或提示用户。

| `verified` | 含义 |
| --- | --- |
| `True` | 这次检查通过 |
| `False` | 检查未通过，答案可能有问题 |
| `None` | 无法完成检查 |

## 各题型怎么检查

| 题型 | 方法 |
| --- | --- |
| 算术 / 化简 | 原式与答案之差应化简为 0；符号检查失败时再做随机取点 |
| 求导 | 中心差分，并用符号求导交叉检查 |
| 不定积分 | 对答案求导，应得到被积函数 |
| 定积分 | 数值积分交叉检查 |
| 极限 | 从指定方向在极限点附近取样 |
| 级数 | 在展开点附近比较多项式和函数值 |
| 微分方程 | 把解代回方程，残差应为 0 |
| 方程 / 方程组 | 每个解代回所有方程 |
| 矩阵 | 分数消元计算行列式和秩；用乘法检查逆矩阵；用特征方程检查特征值 |
| 数论 | 整除、乘法复原和试除，不调用 SymPy 的判定函数 |
| 约束 | 把 Z3 给出的模型代回每条约束 |

这些检查能发现许多计算错误，但不是形式化证明。数值采样有范围和容差。含自由符号、奇点或超时的结果会标成无法验证。

## 明确不覆盖的结论

“无解”没有被独立证明。内置题目里的无解方程和无解约束会求解成功，验证状态是无法验证，而不是通过。不定积分不检查积分常数。验证也不能代替对应用题建模是否正确的判断。
